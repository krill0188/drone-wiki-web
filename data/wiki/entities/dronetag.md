# Dronetag

Remote ID 솔루션 개발 기업. Airwise Solutions와 파트너십을 통해 Remote ID 데이터를 Airwise Nexus 공통 운용 상황도에 통합.

## 핵심 제품

- **Remote ID 솔루션**: 드론 식별 및 위치 정보 브로드캐스트
- **Airwise Nexus 통합**: 원격 식별 데이터와 기타 운용 데이터 결합

## 파트너십

- **Airwise Solutions**: 공역 인식 플랫폼과의 통합
- **목표**: 저고도 공역 활동의 완전한 상황 인식 제공
