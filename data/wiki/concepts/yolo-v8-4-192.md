# YOLO v8.4.192 Release

**버전**: v8.4.192 · **릴리스일**: 2026-10-28 · **분류**: PyTorch 2.15·CUDA 13 호환성 중심의 멀티 GPU 학습/ONNX Runtime GPU 추론 수정 릴리스.^[inbox/processed/fetch-2026-10-30-yolo.md]

## 핵심 변경사항
- **멀티 GPU 학습** — PyTorch 2.8 이상에서 각 NCCL 프로세스 그룹을 해당 학습 rank에 선택된 GPU에 명시적으로 바인딩한다. GPU를 기본 순서가 아니게 선택할 때의 디바이스 불일치 오류를 막는 목적이다.
- **ONNX GPU 추론** — Linux CUDA 환경에서 ONNX Runtime의 CUDA 의존성을 설치하고 라이브러리를 미리 로드한다. cuRAND 누락으로 추론이 CPU로 폴백되는 문제를 줄인다.
- **CUDA 도구** — Docker 학습 이미지가 PyTorch 2.15를 쓰고, export 이미지와 GPU CI에 필요한 ONNX Runtime CUDA 패키지가 포함됐다.
- **문서** — Platform 예측 응답 예시에서 `metadata.classNames`를 제거했다(클래스 이름은 개별 검출에 그대로 있다).

## 영향
릴리스 노트는 모델 아키텍처나 예측 동작 변경이 없다고 밝힌다. 드론 영상 모델을 멀티 GPU 서버에서 학습하거나 ONNX GPU로 추론하는 파이프라인의 환경 안정성 개선이다. 단일 릴리스 노트 기준이다.
