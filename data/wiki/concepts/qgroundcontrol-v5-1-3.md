# QGroundControl v5.1.3 Release Notes

QGroundControl v5.1.3 stable release (2026-08-20) with corrected HUD pitch display and V5.1 feature set.

## Key Changes

- **HUD pitch display correction**: Pitching nose-down now moves the pitch indicator down, matching the roll convention. See HUD documentation for details.

- **V5.1 stable features**: Complete V5.1 feature set including improved UI, enhanced mission planning, and updated vehicle support.
