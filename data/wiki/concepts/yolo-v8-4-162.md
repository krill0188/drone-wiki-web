# YOLO v8.4.162 Release

2026-09-24 릴리스. 모델 아키텍처·가중치 변경 없이, CUDA 예측 시 다음 배치를 워커
스레드에서 미리 로드하는 prefetch가 추가됐다.^[inbox/processed/fetch-2026-09-25-yolo.md]

## 주요 변경사항

- **CUDA 예측 prefetch**: 다중 배치 이미지 전용 탐지(PyTorch 가중치)에서 GPU가 현재 배치를
  처리하는 동안 다음 배치를 로드한다. 다른 장치·태스크·백엔드·영상 혼합 소스는 기존 동작 유지.
- **학습 데이터 준비 가속**: copy-paste 증강, 시맨틱 마스크 타깃 생성 최적화.
- **TensorFlow INT8 export 메모리 절감**: 캘리브레이션 이미지를 사전 할당 배열에 수집.
- **Platform**: 호스팅 텍스트 프롬프트 SAM 3/3.1, 클라우드 스토리지 임포트 50만 객체, 클래스명 이미지 검색.
- **안정성**: Windows OpenVINO 크래시, GPU ONNX 추론의 CPU 무음 폴백, OOM 복구, 동일 파일명 추적 수정.
