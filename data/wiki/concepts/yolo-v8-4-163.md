# YOLO v8.4.163 Release

2026-09-25 릴리스. x86_64 Linux에서도 Apple Core AI 형식(`.aimodel`)으로 내보낼 수 있게 됐다.^[inbox/processed/fetch-2026-09-26-yolo.md]

## 주요 변경사항

- **Linux Core AI export**: Apple silicon Mac(macOS 26 이상) 외에 x86_64 Linux에서도 `.aimodel` export 가능.
  대상은 iOS 27·macOS 27이며 실행에는 여전히 Apple 하드웨어가 필요하다.
- **Core AI 호환 갱신**: `coreai-torch` 0.4.3 지원(변환 중 최적화 수행), Python 3.11–3.14.
- **벤치마크**: Linux에서 Core AI export 결과를 보고하고, macOS가 필요한 추론은 정상적으로 건너뛴다.
- **export 안정성**: 일부 ONNX export용으로 패치된 PyTorch 함수가 export 실패 시에도 복원된다.
- **Docker 이미지 경량화**: 패키지 설치 캐시와 번들 PyTorch 테스트 파일 제거.

## 영향

Linux 클라우드·CI에서 Apple 기기용 모델을 빌드할 수 있다. Core ML은 별도 선택지로 유지된다.
