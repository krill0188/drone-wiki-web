# YOLO v8.4.157 Release

2026-09-20 릴리스. TensorRT FP16/INT8 추론을 최대 20% 가속하는 데 초점을 두고, YOLOE
prompt-free 지원 확대, Apple Silicon 성능, 검증 신뢰성, 학습 안정성을 함께 개선했다.^[inbox/processed/fetch-2026-09-21-yolo.md]

## 주요 변경사항

- **TensorRT 엔진 가속(PR #26223)**: FP16 변환 시 랜덤 노이즈 대신 실제 이미지로
  캘리브레이션해 더 많은 레이어를 안전하게 FP16으로 실행한다. SiLU 활성화를 TensorRT가
  융합할 수 있는 형태로 재작성해 메모리 바운드 커널을 줄이고, 지원되는 정적 TensorRT
  엔진에는 CUDA Graph 리플레이를 추가해 추론당 런치 오버헤드를 낮춘다. 정적 shape
  엔진에서 최대 20% 빠른 FP16/INT8 추론이 기대된다. CUDA Graph는 동적 엔진, DLA 실행,
  NMS 내장 엔진에서는 쓰이지 않는다.
- **YOLOE-26 prompt-free 추론 확대(PR #26201)**: one-to-many/one-to-one 검출 헤드를 모두
  가진 체크포인트를 지원하고, `nms` 설정으로 표준 NMS 추론과 NMS-free 추론을 선택하며,
  `set_vocab()`이 커스텀 prompt-free YOLOE 모델의 양쪽 브랜치를 재생성한다.
- **Apple Silicon CPU/MPS 성능**: 느린 NNPACK 컨볼루션 경로를 비활성화하고, MPS
  box-IoU·task-assignment 연산과 시맨틱 세그멘테이션 `bincount`를 MPS 친화적 방식으로
  교체했으며, 결과 export·플롯·요약의 반복 변환을 줄였다.
- **학습·검증 신뢰성**: AutoBatch가 초기 배치 크기 프로브 실패를 OOM 한계로 오인하지
  않고, 짧은 학습에서도 Mosaic 증강이 정상 종료된다. resume 오류가 실제 체크포인트/설정
  문제를 알려주며, 음수 patience·비양수 이미지 크기 같은 잘못된 설정을 조기에 거부한다.
- **export·데이터셋 동작**: 고정 shape export 모델은 반복 `predict()`에서도 export
  이미지 크기를 유지한다. TAR 데이터셋 추출이 ZIP처럼 실제 최상위 디렉터리를 반환하고,
  시맨틱 마스크 캐시가 `nc=1` 변경을 올바로 처리하며, 단독 검증은 로드된 모델이 지원하지
  않는 클래스 라벨을 건너뛴다. COCO 크기별 지표가 detection/segmentation/pose 태스크에
  올바르게 연결된다.
- **의존성 설치**: 여러 export extras의 Python 버전 마커와 패키지 충돌을 바로잡아
  `uv lock`/`uv sync` 신뢰성을 개선했다.

## 영향

Jetson 등 TensorRT 기반 엣지 장치에서 정적 shape 엔진의 추론 지연이 줄어 드론 탑재
검출 파이프라인의 처리량 확보에 유리하다(드론 관점의 해석). 단, DLA나 NMS 내장 엔진을
쓰는 배포에는 CUDA Graph 이득이 적용되지 않는다.
