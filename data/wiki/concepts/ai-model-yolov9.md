# YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information

- 원문: https://arxiv.org/abs/2402.13616^[inbox/processed/hw-20261021-model-yolov9.md]
- 제작: Chien-Yao Wang, I-Hau Yeh, Hong-Yuan Mark Liao^[inbox/processed/hw-20261021-model-yolov9.md]

## 핵심 사양 (초록)
- PGI(Programmable Gradient Information)와 GELAN(Generalized Efficient Layer Aggregation Network, 일반 합성곱만 사용)을 제안. MS COCO 평가.^[inbox/processed/hw-20261021-model-yolov9.md]
- PGI로 처음부터 학습한 모델이 대규모 데이터 사전학습 SOTA를 능가한다고 주장. 코드: github.com/WongKinYiu/yolov9. 제출 2024-02-21.^[inbox/processed/hw-20261021-model-yolov9.md]
