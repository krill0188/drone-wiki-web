# YOLO v8.4.150 Release

**버전**: v8.4.150
**릴리스일**: 2026-09-12
**분류**: 보안 체크포인트 로딩 개선 + YOLOE 호환성 복구 + RT-DETR 학습 효율화

## 핵심 변경사항

- **제한 체크포인트 로딩 고속화 (PR #26155)** — 체크포인트가 실제로 참조하는 모델 클래스만
  선별 해석하도록 바꿔, 지원되는 모든 모델 모듈을 매번 import/스캔하던 방식을 제거. 기존 신뢰
  네임스페이스·별칭·등록 잠금·허용목록 동작은 그대로 보존. 융합된(fused) YOLOE 체크포인트에
  필요한 안전한 `forward`/`forward_fuse` 바인딩을 복구했고, 거부된 객체 타입을 부분 복원된
  모듈에 `repr()`을 호출하지 않고 표시하도록 오류 메시지를 개선. 레거시 NumPy 메타데이터와
  임베디드 Ultralytics CLIP 객체도 제한 로딩 중 지원.
- **진단 안전성 및 Ray Tune 호환성 (PR #26151)** — Sentry가 자격증명이 포함될 수 있는
  명령줄 인자·로컬 변수를 수집하지 않도록 방지. Ray 버전을 2.41.0 이상으로 강제하고 구버전
  Ray 호환 코드를 제거.
- **RT-DETR 고밀도 데이터셋 학습 효율화 (PR #26150)** — 서로 다른 이미지의 예측-타겟 간
  매칭 비용 계산을 회피해 불필요한 비용 저장·패딩 오버헤드를 감소. SKU-110K처럼 이미지당
  객체 수가 많은 데이터셋에서 효과가 가장 큼. 할당 solver·손실 함수·정밀도·학습 설정은
  변경 없음.
- **YOLO27 프리뷰 문서** — "Coming Soon" 라벨의 YOLO27 모델 페이지 공개(예상 아키텍처,
  지원 태스크, 예비 벤치마크, 향후 사용 예제). README/문서 전반에 디스커버리 링크 추가.
  가중치·패키지 지원·출시일은 아직 미확정이며, **YOLO26이 현재 권장 릴리스 모델**임을 명시.
- **Ultralytics Platform 배포 문서 확장** — 유료 엔드포인트의 CPU/메모리 설정, uptime
  과금, scale-to-zero 동작, 경량 모니터링 문서화. 예측 예시·통계는 엔드포인트 중지/재시작/
  재배포/리사이즈/교체 시 소실될 수 있음을 명시하고, 영속 저장을 위해 데이터셋에 저장하는
  방법을 설명.
- **모델 벤치마크 표 정리** — YOLO26·YOLO11·YOLOv8·YOLOv9·YOLO12·YOLOE·SAM·YOLO-NAS 등
  전 모델군 문서에서 최고 정확도/속도/지연/크기/파라미터/연산량 값에 대한 굵게 표시 규칙을
  통일(수치 자체는 변경 없음).
- **버전 갱신**: 8.4.148 → 8.4.150.

## 영향

제한 로딩 경로가 필요한 모델 클래스만 해석하게 되어 커스텀/구버전 체크포인트를 다루는
프로덕션 파이프라인의 로딩 속도와 신뢰성이 개선되고, 특히 융합 YOLOE 체크포인트의 정상
동작이 복구되었다. RT-DETR 개선은 드론 온보드처럼 프레임당 객체 수가 많은 고밀도 검출
데이터셋 학습 시간을 줄여준다.
