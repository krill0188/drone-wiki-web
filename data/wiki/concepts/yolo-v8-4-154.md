# YOLO v8.4.154 Release

2026-09-16 릴리스. CoreML 동적 export 수정, RT-DETR OpenVINO INT8 export 정확도
복원, GPU 훈련 속도 개선, SAM3 마스크 처리 메모리 효율화, 분류 검증 클래스
인덱스 오류 방지가 핵심이다.^[inbox/fetch-2026-09-17-yolo.md]

## 주요 변경사항

- **CoreML 동적 export 수정(PR #26199)**: 탐지·분할·포즈·OBB 모델이 `dynamic=True`
  export 시 `coremltools`의 `arange` 변환 오류 없이 export 가능. 정적 CoreML
  모델도 다중 이미지 배치를 첫 이미지만 처리하던 문제를 수정해 정상적으로
  처리하도록 개선.
- **RT-DETR OpenVINO INT8 export 정확도 복원**: RT-DETR 디코더를 부동소수점으로
  유지하면서 NNCF 트랜스포머 인지 양자화 적용. RT-DETR-L 정확도가 약 0.0002에서
  0.6513 mAP50-95로 복원, CPU 추론 속도는 거의 그대로 유지.
- **GPU 훈련 속도 개선**: 불필요한 메모리 초기화·활성화 복사·호스트-디바이스
  동기화·EMA 상태 재구성 회피, fused Adam/AdamW 옵티마이저 지원. B200 GPU에서
  YOLO26x COCO 훈련 스텝이 228.9ms→183.5ms로 약 1.25배 개선(측정 환경 기준).
- **SAM3 마스크 처리 메모리 효율화**: 대형 시맨틱 마스크를 한 번에 업스케일하지
  않고 제한된 청크 단위로 처리해 수 기가바이트급 임시 메모리 할당을 방지.
- **분류 검증 클래스 인덱스 오류 방지**: 검증/훈련 분할이 폴더별 알파벳 순서
  대신 모델의 클래스 이름에 정렬되도록 수정, 모델에 없는 클래스는 경고와 함께
  건너뛰어 잘못된 정확도·모델 선택 지표를 방지.
- **Platform 훈련 콜백 SDK 전환**: 중복된 raw HTTP/재시도 로직을 생성된 SDK로
  대체, 인증·취소·체크포인트 서명·페이로드 정제를 유지한 채 제어된 POST 재시도
  추가(`ultralytics-platform>=0.1.45` 필요).
