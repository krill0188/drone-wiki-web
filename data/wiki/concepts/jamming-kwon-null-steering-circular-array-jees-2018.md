# Null Steering of Circular Array Using Array Factor for GPS Anti-Jam

- 원문: https://doi.org/10.26866/jees.2018.18.4.267^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]
- 저자: Taek-Sun Kwon, Jae-Gon Lee, Jeong-Hae Lee^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]
- 발행: 2018-10-31 (Journal of Electromagnetic Engineering and Science, vol. 18, no. 4, pp. 267-269)^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]

## 핵심 내용
GPS 안티재밍용 원형 배열의 널 스티어링을 수정한 배열 인자(AF)로 구현한 레터. mu-zero resonance(MZR) 원편파 안테나 7소자를 중심 방향으로 배치하고, 각 소자의 회전각을 반영해 AF 를 수정했다. AF 가 0이 되는 방향에 널이 생기도록 입력 포트 위상을 계산하고, L2 대역(1.2276 GHz)에서 전력분배기 2종을 제작해 특정 각도의 패턴 널링을 구현, 시뮬레이션과 측정 패턴을 비교해 확인했다.^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]

## 설계·운용에 쓸 수 있는 지침 (원문 수치만)
- 7소자 원형 배열, 동작 L2 1.2276 GHz (초록)^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]
- 소자 회전각 보정이 필요한 AF 수정이 핵심^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]
- 널 깊이(dB), 소형 드론 탑재 크기는 초록에 없음^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]

## 한계·미확인
UAV 적용 직접 언급 없음. 널 깊이·배열 크기·무게 미확인. 한국 저자 논문이나 KCI 등재 여부는 확인 못 함.^[inbox/processed/hw-20261021-jamming-kwon-null-steering-circular-array-jees-2018.md]
