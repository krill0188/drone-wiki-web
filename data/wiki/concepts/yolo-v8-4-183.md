# YOLO v8.4.183 Release

**버전**: v8.4.183
**릴리스일**: 2026-10-20
**분류**: 하드웨어 배포 확대(Axelera, Intel LiteRT)와 학습·데이터·예측 안정성 수정

이전 기록은 [[yolo-v8-4-182]], 프레임워크 개요는 [[yolo]] 참조.

## 핵심 변경사항
- **Axelera Metis**: Voyager SDK 1.9.0으로 YOLO26 전 태스크(검출, 인스턴스·시맨틱 분할, 깊이, 포즈, OBB, 분류)를 export·predict·validate 가능. NMS-free 검출 경로가 기본이며 `metis-dkms` 1.7.0 이상이 필요하다. 문서화된 COCO128 벤치마크에서 배치 32 기준 SDK 1.8의 40장/초 → SDK 1.9 109장/초.^[inbox/processed/fetch-2026-10-21-yolo.md]
- **Intel LiteRT**: LiteRT export 모델을 Intel CPU·NPU에서 실행할 수 있다.^[inbox/processed/fetch-2026-10-21-yolo.md]
- **안정성 수정**: warmup·gradient accumulation 경계 사례, MPS 메모리 증가, 깊이 보정이 더 나쁜 값으로 교체되는 문제, 분류기 라벨 정렬(ImageNette 검증 정확도 9.45% → 70.37%로 보고), FastSAM 음수 점 처리, 매우 얇은 이미지·직사각형 INT8 보정 등.^[inbox/processed/fetch-2026-10-21-yolo.md]

## 드론 관점
엣지 NPU 배포 선택지가 늘어 온보드 추론 구성에 참고가 된다. 드론 전용 수치는 릴리스 노트에 없다. 관련: [[computer-vision-drone]], [[companion-computer]].
