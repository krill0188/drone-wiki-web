# YOLO v8.4.126 Release Notes

YOLO v8.4.126 (2026-08-21) makes restricted checkpoint loading safer and up to 40% faster in concurrent environments, while simplifying RLE loss calculations and preserving backward compatibility.

## Key Changes

- **Thread-safe restricted checkpoint loading**: Fixed a race condition when multiple threads loaded PyTorch checkpoints with restricted loading enabled. The shared allow-list is now registered for the process lifetime.

- **Faster restricted model loading (~40% improvement)**: Only checkpoint globals actually referenced by a file are registered, reducing overhead.

- **Improved compatibility with secure loading**: Requires PyTorch 2.6+; older versions fall back to standard loading. Official YOLO26 checkpoints protected from concurrent loading failures.

- **Simplified RLE prior calculation**: Replaced runtime multivariate distribution with closed-form implementation, improving numerical behavior under mixed-precision training.

## Impact

- More reliable production inference for multi-threaded services
- Reduced startup and loading time for frequently loaded models
- Maintained security benefits with safe loading
- Backward compatible with existing workflows
