# YOLO v8.4.112

Ultralytics YOLO v8.4.112 릴리스 (2026-07-29). 모델 내보기(export) 지원 개선 및 DEEPX 분류 모델 내보기 버그 수정.

## 주요 변경사항

### Export 포맷 지원 문서화
- 20개 통합 페이지에 지원 작업(Supported Tasks) 테이블 추가
- 7가지 Ultralytics 작업 명시:
  - Object detection
  - Instance segmentation
  - Semantic segmentation
  - Pose estimation
  - OBB detection
  - Classification
  - Depth estimation

### 포맷별 검증
- 77개 로컬 내보기 및 추 검증 완료
- TorchScript, ONNX, OpenVINO, CoreML, TensorFlow 등 지원
- TensorRT 및 RKNN는 CI 테스트 매트릭스로 확인

### DEEPX 분류 모델 수정
- 분류 모델용 캘리브레이션 데이터셋 발견 수정
- `root` 경로 처리 개선
- 모든 작업별 기본 모델로 스모크 테스트 업데이트
