# YOLO v8.4.155 Release

2026-09-17 릴리스. 데이터셋 캐시 안전성, export 신뢰성, 훈련 검증, 플랫폼
호환성을 개선해 YOLO26 워크플로의 실패율을 낮추는 데 초점을 맞췄다.^[inbox/fetch-2026-09-18-yolo.md]

## 주요 변경사항

- **`labels.cache` 재사용 오류 방지(PR #26207, 핵심 변경)**: 클래스 수, 키포인트
  설정, 탐지/포즈 구분, 단일 클래스 모드 등 스캔 설정을 캐시 검증에 포함시켜
  `data.yaml` 변경 시 캐시된 비호환 라벨을 재사용하지 않고 새로 스캔하도록 수정.
- **잘못된 epoch 값 조기 거부**: `epochs=0` 또는 음수 설정 시 100 epoch로 조용히
  실행되던 기존 동작 대신 검증 오류를 즉시 발생.
- **Windows OpenVINO 추론 개선**: Windows CPU 추론이 FP32 정밀도를 명시적으로
  요청해 저정밀도 커널 실패를 방지.
- **자동 의존성 설치 제어 강화**: `YOLO_AUTOINSTALL=False` 설정 시 `apt` 자동
  설치와 Edge TPU 컴파일러 설정까지 함께 차단.
- **YOLO26 포즈 훈련 Apple MPS 지원 수정**: RLE 포즈 손실 가중치를 올바른
  `float32` 타입으로 수정해 MPS 디바이스에서 훈련 가능.
- **폰트 검색 속도 개선**: Matplotlib 캐시된 폰트 목록을 우선 사용해 macOS 등에서
  시작 시간 단축.
- **export/추론 경로 개선**: LiteRT 변환이 평가 모드를 명시적으로 사용, MNN
  예제의 좌표 박스 클램핑 오류 수정, OBB 각도 데이터를 디코딩 중 직접 전달.
- **분산 훈련 호환성 갱신**: 신형 PyTorch 버전에 맞는 버퍼 동기화 옵션 적용.
