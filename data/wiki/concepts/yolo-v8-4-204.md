# YOLO v8.4.204 릴리스 (2026-11-06)

Ultralytics 공식 GitHub 릴리스 노트(v8.4.204, 2026-11-06) 기준 요약이다.^[inbox/processed/fetch-2026-11-07-yolo.md]

## 요약
학습·검증·예측 전반에서 고해상도 타일링(`tile`)을 쓸 수 있게 됐고, FastSAM 텍스트 프롬프트, 내보내기·INT8 보정, 데이터셋 처리가 개선됐다.

## 주요 변경사항
- **고해상도 타일링**: `tile=True` 또는 양의 정수 타일 크기를 주면 큰 이미지를 겹치는 창으로 처리한다. 학습은 라벨을 타일별로 잘라내고, 검증·예측은 결과를 원본 이미지로 병합한다. 새 High Resolution Tiling 가이드가 추가됐고, SAHI 가이드는 내장 `tile` 옵션을 안내하는 폐기 예고(deprecation) 문구와 함께 유지된다.
- **FastSAM 텍스트 프롬프트**: DataComp-XL CLIP 모델을 써서 올바른 마스크를 더 자주 고르며, 속도와 다운로드 크기는 비슷하다.
- **LiteRT 양자화 가속**: INT8·w8a16 보정에 C++ 프로파일링 모드를 사용한다. 보고된 벤치마크에서 내보내기 시간이 약 36초에서 11초로 줄었고 검증 정확도 저하는 측정되지 않았다.
- **내보내기·보정 안정성**: INT8 보정이 NDJSON·Platform 데이터셋을 지원한다. NCNN 내보내기는 런타임이 못 읽는 모델을 오류로 알리고, TensorFlow·RKNN·Axelera·Xilinx 내보내기 의존성 문제가 수정됐다.
- **기타**: SM 12.1 GPU(GB10, N1X)에서 RT-DETR INT8 내보내기 실패 회피, 학습 재개 시 새 증강 난수 사용, 따옴표 키 뒤 공백이 있는 YAML 파싱 허용.

## 목적·영향
- 항공 영상처럼 큰 이미지의 소형 객체 세부를 별도 타일링 패키지 없이 보존할 수 있다. 다만 모델 추론 횟수가 늘어 시간·메모리가 더 든다(릴리스 노트).
- 내보내기·보정 변경은 해당 하드웨어·포맷의 배포 흐름을 빠르고 안정적으로 만든다.
