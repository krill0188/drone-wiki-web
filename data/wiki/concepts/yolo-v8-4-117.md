# YOLO v8.4.117 릴리스

Ultralytics YOLO v8.4.117 릴리스(2026-08-09). 증강 정확도, 모델 신뢰성, 배포 보안, 문서 정비가 핵심이다.^[inbox/fetch-2026-08-10-yolo.md]

## 주요 변경

- **Albumentations 공간 변환 타입별 처리**: 하드코딩된 변환명 목록 대신 재귀적 타입 감지로 교체 — `OneOf` 같은 래핑된 변환도 바운딩박스/폴리곤/마스크/깊이맵/키포인트를 정확히 갱신
- **의존성 설치 보안 강화**: `check_requirements()`가 신뢰할 수 없는 requirement 문자열이 셸 명령으로 해석되지 않도록 차단 — 모델 파일 로드 시 자동 의존성 설치 워크플로 보호
- **데이터셋·마스크 처리 신뢰성**: Windows 시맨틱 마스크 shape 처리 수정(Mosaic 증강 중 그레이스케일 마스크 실패 해결), COCO 변환 라벨 포맷 일관성 확보
- **깊이 추정 개선**: PyTorch/Hailo/익스포트 모델 출력 정렬 후 패딩 제거로 백엔드 간 일관성 향상, KITTI 깊이 설정을 표준 652프레임 좌측카메라 평가 분할로 전환
- **추론 속도**: YOLO26 종단간 후처리가 grouped top-k 선택 사용 — TensorRT FP16 지연시간 약 1.8~8.1% 개선(mAP 변화 없음)
