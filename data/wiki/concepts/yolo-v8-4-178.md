# YOLO v8.4.178 Release

**버전**: v8.4.178
**릴리스일**: 2026-10-16
**분류**: Platform 링크 신뢰성 + 검증·트래킹·내보내기 호환성 수정 (신규 모델 아키텍처 없음)

이전 버전은 [[yolo-v8-4-177]], 프레임워크 개요는 [[yolo]] 참조.

## 핵심 변경사항
- **Platform 학습 링크**: 서버가 반환한 모델 URL을 출력해 소유자·프로젝트·모델명이 다를 때 깨진 링크를 막는다. 서버 URL이 없으면 링크를 출력하지 않는다(PR #26699).^[inbox/processed/fetch-2026-10-17-yolo.md]
- **벤치마크**: 의료·소매·산업·항공 영상 등 37개 실세계 검출 데이터셋의 고정 평가 프로토콜을 설명하는 Ultralytics Benchmark 페이지가 추가되었고, YOLO27 문서의 성능 수치가 갱신되었다.^[inbox/processed/fetch-2026-10-17-yolo.md]
- **호환성**: YOLO-NAS 로딩·예측·검증·내보내기·ReID 트래킹 수정, FastSAM 프롬프트가 이후 이미지·프레임에 유지, SAM 트래킹이 빈 마스크에서도 객체 ID 보존, 회전 박스 트래킹 일관성 개선.^[inbox/processed/fetch-2026-10-17-yolo.md]
- **검증·내보내기**: 정적 내보내기에 기록된 비정방 입력 형상 존중, Apple MPS의 TorchScript 로딩·동적 ONNX 실행 및 정수 LiteRT/TensorFlow 입력 처리 수정.^[inbox/processed/fetch-2026-10-17-yolo.md]
- **학습 신뢰성**: TensorBoard writer 정상 종료, 체크포인트에 FP32 옵티마이저 모멘텀 유지, Ascend NPU 미지원 reduction 회피, Docker 태그 덮어쓰기 방지.^[inbox/processed/fetch-2026-10-17-yolo.md]

## 드론 관점
엣지 배포 형식(ONNX/LiteRT)과 항공 영상 포함 벤치마크가 관련된다. 관련: [[computer-vision-drone]].

## 최신 근거 연결 (2026-10-18)

- 후속 릴리스 [[yolo-v8-4-181]]에서 회전 박스 트래킹의 각도가 프레임 사이에서 뒤집히지 않도록 추가 보정되었다(이 릴리스의 회전 박스 트래킹 일관성 개선에 이은 변경).^[inbox/processed/fetch-2026-10-18-yolo.md]
