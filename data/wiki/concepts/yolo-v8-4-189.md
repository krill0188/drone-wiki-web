# YOLO v8.4.189 Release

**버전**: v8.4.189 · **릴리스일**: 2026-10-25 · **분류**: 배포 신뢰성·추론 견고성 개선 릴리스. 모델 아키텍처 변경은 없다.^[inbox/processed/fetch-2026-10-26-yolo.md]

## 핵심 변경사항
- **IMX500 내보내기 안정화** — 변환기 요구사항과 의존성 버전을 정렬했다. IMX500 export는 Linux + Python 3.10–3.12에서만 명시적으로 지원한다.
- **Hailo 세그멘테이션 export 수정** — 세그멘테이션 prototype 출력 노드를 export된 모델에서 직접 탐지해 활성화 함수가 다른 모델도 수용한다.
- **ONNX 저 opset 호환** — 여러 `einsum` 연산을 행렬곱으로 대체해 YOLOE·YOLO-World 모델이 낮은 opset으로 ONNX export 가능하다.
- **예측 결과 견고성** — 분류 확률이 추론 호출 간 보존되고, 그레이스케일 이미지와 박스 없는 결과를 더 안전하게 처리한다.
- **TensorFlow export** — Windows ML·Vitis AI 등 기존 ONNX Runtime 변형을 인식해 불필요한 런타임 교체를 피한다.
- **데이터셋 오류 메시지** — 읽을 수 없는 데이터셋이 "라벨 없음"으로 오보되는 경우를 줄였다.
- **모바일 가이드** — LiteRT·QNN·Core ML 벤치마크 표 갱신, Platform export를 Ultralytics YOLO 앱에서 여는 방법 문서화.

## 영향
Jetson·Hailo·IMX500 같은 엣지 가속기에 탐지 모델을 올리는 드론 온보드 파이프라인의 export 실패 가능성을 낮춘다. 단일 릴리스 노트 기준이다.
