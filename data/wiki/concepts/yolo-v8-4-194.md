# YOLO v8.4.194 Release

**버전**: v8.4.194 · **릴리스일**: 2026-10-30 · **분류**: AutoBatch 신뢰성 개선과 모델 로딩·결과 저장·데이터셋 처리 수정 릴리스.^[inbox/processed/fetch-2026-10-31-yolo.md]

## 핵심 변경사항
- **AutoBatch** — 모든 태스크에서 학습 데이터셋을 사용해 배치 크기를 정한다. 분류·검출·멀티 데이터셋 학습에서 데이터셋 크기와 라벨을 반영하며, 프로파일링 중 backward 계산에서 메모리가 부족하면 이를 한계로 취급한다.
- **모델 YAML 파싱** — activation은 지원되는 `torch.nn` 모듈로 해석돼야 하고 모델 항목은 PyTorch 모듈 클래스여야 한다. 다른 표현을 쓰는 커스텀 YAML은 수정이 필요할 수 있다.
- **결과 저장** — `Results.save()`와 `plot(save=True)`가 웹캠·영상·경로 없는 소스에서도 적절한 `.jpg` 파일명을 만들고 필요 시 상위 디렉터리를 생성한다.
- **유사도 검색** — 시작할 때마다 선택한 이미지 디렉터리를 사용해 다른 데이터셋의 오래된 인덱스 재사용을 막는다(대신 임베딩을 매번 다시 만든다).
- **데이터셋·URL** — PNG가 아닌 시맨틱 마스크를 캐시 해시 전에 처리하고, `HTTPS://`·`GS://`·`UL://` 같은 URL 스킴을 대소문자 구분 없이 처리한다.
- **벤치마크·문서** — TensorFlow GraphDef 벤치마크에 OBB·pose가 추가됐고, 검증에 없는 클래스는 측정된 클래스별 점수가 아니라 전체 mAP 값을 받는다는 설명이 문서에 들어갔다.

## 영향
새 모델 아키텍처는 없다. 작은 데이터셋·제한된 GPU 메모리에서 학습할 때 배치 크기 오선택 가능성이 줄고, 커스텀 모델 YAML을 쓰는 드론 검출 파이프라인은 호환성 확인이 필요하다. 단일 릴리스 노트 기준이다.
