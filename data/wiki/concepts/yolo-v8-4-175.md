# YOLO v8.4.175 Release

Ultralytics 8.4.175(2026-10-09)는 새 모델 아키텍처 없이 학습·검증·추론·배포 신뢰성을 높인 릴리스다. 핵심 수정은 분할 비율을 바꿨을 때 분류 이미지가 학습/검증 양쪽에 동시에 남던 문제다.^[inbox/processed/fetch-2026-10-10-yolo.md]

## 주요 변경사항

- **분류 분할**: 비율 변경으로 이미지가 재배정되면 이전 분할의 사본을 제거한다. 중첩 클래스 폴더 경로와 캐시·분할 디렉터리는 보존된다. 검증 지표의 데이터 누수를 막는다.
- **모델 로딩**: 사전학습 클래스 이름 이전, 그레이스케일 모델의 RGB 가중치 활용 개선, 클래스 수를 줄인 파인튜닝에서 학습된 특징 보존 확대. YAML로 만든 pose 모델에 예측용 키포인트 메타데이터를 부여한다.
- **검증**: 컴파일된 검증이 마지막 부분 배치를 건너뛰지 않는다. 대형 시맨틱 분할 픽셀 수 오류와 라벨 없는 COCO 키포인트 처리도 수정됐다.
- **입력 처리**: 16-bit 이미지, 오래된 이미지 캐시, 멀티페이지 TIFF, 확장자 없는 URL, 영상 확장자가 붙은 RTSP/RTMP/TCP 소스.
- **export**: 내장 NMS export의 큰 추론 배치, 빈 프레임 CoreML, 동적 YOLOE CoreML, export 모델의 입력 크기 기본값.
- **트래킹·깊이**: 트래커 ID를 트래커별로 분리하고, 깊이 예측이 검증·보정과 같은 이미지 스트레칭을 쓴다.
- **문서·CI**: Platform 워크플로, 보안·컴플라이언스, Hailo 벤치마크 문서. CI는 공유 `uv` 설정과 실패 알림을 도입했고 CUDA Docker 이미지는 PyTorch 2.14.1로 올렸다.
