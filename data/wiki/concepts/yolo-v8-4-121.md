# YOLO v8.4.121 Release

YOLO v8.4.121 improves OpenVINO INT8 export reliability for YOLO26 models with broad Platform API, dataset, annotation, deployment, and documentation updates.

## Key Changes

### OpenVINO INT8 Export
- Replaced fragile PyTorch-based layer matching with exact names from converted OpenVINO graph
- Keeps Detect decoding, DFL, and Sigmoid operations in floating point
- Preserves strict NNCF validation during quantization
- Verified YOLO26n-P2 INT8 export using 55 exact ignored operations
- No unwanted `FakeQuantize` nodes

### Platform API Documentation
- Documented `ultralytics-platform` Python SDK alongside REST examples
- Updated endpoint paths, authentication, pagination, rate limits
- Coverage for images, dataset ingestion, exports, storage, billing, training, deployments

### Dataset and Annotation
- Clearer documentation for URL, cloud-storage, On Premise imports
- Class merging/deletion, conflict handling, readiness checks
- COCO and NDJSON import support
- Annotation visibility controls and keyboard shortcuts

### Security and CI
- Prevented checkout credentials in Docker images
- Workflow secrets in environment variables
- Dependabot checks changed from daily to weekly
