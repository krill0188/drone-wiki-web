# YOLO v8.4.141 Release

**버전**: v8.4.141
**릴리스일**: 2026-09-05
**분류**: Axelera 엣지 가속기 지원 강화 (Voyager SDK 1.8.0 업그레이드) + 레거시 호환성 수정

## 핵심 변경사항

- **Axelera Voyager SDK 1.8.0 업그레이드** — export/inference가 `axelera-devkit`/`axelera-rt`
  1.8.0으로 통일, export 환경이 Python 3.13 및 더 넓은 PyTorch 범위를 지원. 기존 SDK로 export한
  모델은 재-export 필요(신규 컴파일 포맷).
- **Axelera 배치 추론 지원** — `batch>1` 예측이 Voyager 스케줄러를 경유하도록 라우팅(단일 디바이스
  상 종단간 속도 향상은 보장하지 않음, 워크플로 호환성 목적).
- **Metis 커널 드라이버 1.6.2+ 요구사항 명시** — 배포 요구사항 문서화 강화. YOLO26 semantic
  segmentation은 지원, instance segmentation은 Ultralytics export 명령으로 아직 미지원.
- **레거시 SPPF 모델 재구성 버그 수정** — pre-YOLO26 YAML 설정에서 SPPF 레이어가 잘못된 활성화
  함수로 재구성되던 문제 해결(YOLO8/10/11/26 회귀 테스트 커버리지 확대).
- **OpenVINO 의존성 opt-in 전환** — OpenVINO/NNCF를 `export-base`에서 `export-openvino` 전용
  extra로 분리, 불필요한 설치 감소(`export` 통합 extra는 계속 포함).
- **Conda CI 의존성 해석 개선** — `conda-forge` 단일 채널 + strict priority, 20분 타임아웃으로
  의존성 해석 지연에 의한 CI 정지 방지.

## 영향

Axelera 엣지 가속기 배포 파이프라인의 신뢰성과 배치 추론 호환성이 개선됐으나, 기존 Axelera
export 모델은 SDK 업그레이드 후 재-export가 필요하다. 레거시 YAML 기반 모델 재구성 버그 수정은
드론 임베디드 배포에서 과거 릴리스 모델을 재현할 때 안전성을 높인다.
