# YOLO v8.4.165 Release

2026-09-28 릴리스. 패키지 호환성, export/추론 신뢰성, 데이터셋 처리를 개선한 유지보수
릴리스다.^[inbox/processed/fetch-2026-09-29-yolo.md]

## 주요 변경사항

- **Python wheel 설치 개선**: 테스트 파일이 더 이상 top-level `tests` 패키지로 설치되지 않아
  다른 프로젝트와의 충돌을 방지(소스 배포에는 유지되어 Conda 빌드 테스트는 그대로 동작).
- **더 신뢰성 있는 export/추론**: ONNX export가 요청된 opset이 모델에 충분한지 검사해 부족하면
  명확한 오류를 반환. Windows OpenVINO 추론이 일부 환경에서 크래시를 유발하던 CPU 명령 경로를
  회피.
- **깊이/시맨틱 출력 개선**: 깊이 리사이즈가 학습/검증과 동일한 정렬 규칙을 따르도록 수정,
  저장된 시맨틱 예측 마스크가 letterbox 패딩 없이 원본 이미지 크기로 복원되며, 잘못된
  시맨틱 클래스 ID를 데이터셋 스캔 중 플래그.
- **데이터셋 처리 안전성**: 공백만 있는 라벨, 동일 바운딩박스를 공유하는 별개 세그멘테이션
  폴리곤, 반복 가능한 분류 데이터셋 분할, 구버전 Albumentations 호환, COCO/LVIS 변환 중첩
  경로 처리 등을 수정. 멀티스펙트럴 변환은 출력이 충돌하거나 쓰기 실패 시 원본 이미지를
  보존하도록 개선.
- **비전 유틸리티 정확도 향상**: left-top-width-height 박스 플립 보정, 추적된 pose 키포인트가
  트랙 ID별 색상을 유지, 거리 계산 선택 로직 개선, 분석 차트의 클래스 히스토리 수정 버그.

## 영향

Conda 등 소스 기반 빌드와 pip wheel 설치 간 `tests` 패키지 충돌이 해소되고, ONNX export
실패가 opset 부족 시점에서 조기에 명확히 드러난다. Windows OpenVINO 배포의 네이티브 크래시
위험이 낮아지고, 데이터셋 오류를 더 이른 단계에서 잡아내며 멀티스펙트럴 변환 중 원본 데이터
손실 위험이 줄어든다.
