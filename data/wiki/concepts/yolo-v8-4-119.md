# YOLO v8.4.119

Ultralytics YOLO v8.4.119 릴리스 (2026-08-13). Intel NPU 분류 성능 개선, 검출 및 추적 안정성 강화, Platform 통합 확장이 주요 특징이다.

## 주요 변경사항

### OpenVINO NPU_TURBO for Classification
- 지원되는 Intel NPU 장치에서 분류 모델 실행 시 `NPU_TURBO` 자동 활성화
- 장치가 지원을 광고할 때만 적용, 다른 작업/장치/드라이버는 기존 동작 유지
- Intel Core Ultra 9 185H에서 약 **42–52%** 분류 지연 시간 개선
- 테스트된 구성에서 비트 동일 정확도 유지
- 터보 모드는 의도적으로 분류에만 제한 (더 큰 이미지 크기에서는 이점이 거의 없고 불필요한 전력 소모 가능)

### Platform SDK 노출
- Python 3.11+ 사용자는 메인 패키지에서 `Platform`, `AsyncPlatform`, `APIError`, `APIConnectionError`에 직접 액세스 가능
- 지연 로딩(lazy imports)으로 필요할 때만 SDK 로드
- Python 3.8–3.10 사용자는 Platform 내보기 요청 시 명확한 호환성 메시지 수신

### Platform 훈련 콜백 효율화
- 후속 메트릭, 텔레메트리, 모델 업로드가 등록된 모델 ID를 재사용
- 프로젝트 및 모델 이름을 반복적으로 해석하는 대신 재사용하여 내부 Platform 트래픽 감소 및 장기 훈련 실행 중 안정성 향상

### 추적 강건성 개선
- BYTETracker가 트랙 생성 전에 너비 또는 높이가 0 이하인 검출을 무시하여 잘못된 Kalman 필터 상태 방지
- Kalman 필터 작업이 불필요한 행렬 연산 대신 직접 슬라이싱 사용으로 단순화
- 다중 객체 추적 경로에서 중복 배열 복사 제거

### 검출 내보기 후처리 안전성
- 검출 top-k 선택이 사용 가능한 앵커 수로 제한됨
- 매우 작은 입력 크기에서 내보기 실패 방지, 표준 입력에 대해서는 정상 동작 유지

### CopyPaste 증강 확률 수정
- `CopyPaste` 변환이 플립 모드에서 구성된 확률을 존중하도록 수정
- 이전에는 적격 이미지가 조건부 없이 증강을 받을 수 있었음

### 문서 및 사용성 업데이트
- 지원되는 모든 7가지 작업(의미론적 분할 및 깊이 추정 포함)을 커버하는 지원 작업 배너 업데이트
- Platform 주석 가이드에 `Cmd/Ctrl+Delete` 이미지 삭제 단축키 추가
- YOLO26 LiteRT 내보기 및 모바일 배포 튜토리얼 비디오 추가
- 문서에서 라이트, 다크, 시스템 테마 컨트롤 복원
- 라이브 사이트에서 올바르게 렌더링되지 않는 문서 임베드 제거
- Python의 내장 문자열 연산을 사용한 ASCII 문자열 검사 개선으로 더 빠른 주석 렌더링
