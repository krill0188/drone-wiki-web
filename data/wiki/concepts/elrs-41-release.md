# ELRS 4.1 릴리스

ExpressLRS 4.1 버전의 주요 개선사항 — 바인딩 프로세스 간소화 및 안정성 향상.

## 주요 개선사항

### 1. 동적 전력 관리 (Dynamic Power)
- 더 스마트한 동적 전력 조정

### 2. 텔레메트리 개선
- "Telemetry Lost" 문제 해결

### 3. PWM 출력 안정성
- 더 안정적인 PWM 출력

### 4. 배터리 센서 캘리브레이션
- 아날로그 vBat 센서 캘리브레이션 지원

### 5. 바인드 프레이즈 설정
- 트랜스미터에서 바인드 프레이즈 직접 설정 가능
