# YOLO v8.4.171 Release

Ultralytics 8.4.171(2026-10-01)은 AMD GPU(ROCm/MIGraphX)에 대한 엔드투엔드 지원을 추가하고,
데이터셋 처리·모델 export·태스크별 동작의 버그를 수정한 릴리스다.^[inbox/processed/fetch-2026-10-02-yolo.md]

## 주요 변경사항

- **AMD ROCm/MIGraphX 지원**: 지원되는 AMD GPU에서 ROCm으로 네이티브 PyTorch 모델을 학습·실행하고,
  MIGraphX 실행 공급자(execution provider)로 export된 ONNX 모델을 구동할 수 있다. 지원 시스템에서
  공급자가 자동 선택되며, MIGraphX 미가용 시 CPU로 폴백한다.
- **AMD 배포 옵션**: ROCm 기반 `latest-amd` Docker 이미지, AMD GPU CI 테스트, 설정/사용 가이드 추가.
  MIGraphX 지원은 Linux x86_64 + Python 3.11 이상을 대상으로 한다.
- **ONNX 재시작 속도 개선**: MIGraphX 컴파일 모델을 캐싱해 이후 로드 시 재컴파일을 피한다. Radeon
  8060S 벤치마크에서 ONNX/MIGraphX가 PyTorch ROCm 대비 동일 정확도·더 빠른 추론을 기록(첫 실행은
  컴파일 시간 소요).
- **데이터셋/학습 버그 수정**: 캐시 모드 전반에서 기존 이미지 캐시 읽기 복원, 아카이브 타임스탬프
  보존으로 불필요한 라벨 재스캔 방지, RT-DETR denoising query 매칭 오류 수정.
- **Export/태스크 버그 수정**: Core ML NMS export의 임시 저장공간 사용 축소, LiteRT/RKNN 포즈
  키포인트 스케일링 개선, 마스크/analytics 동작 다수 수정.
- 신규 모델 아키텍처 도입은 없으며, 핵심은 AMD 하드웨어 지원 확대와 버그 수정.
