# ShadowfaxUAS SF45

ShadowfaxUAS SF45는 남아프리카 제조업체 ShadowfaxUAS가 출시한 ITAR-free, 비중국산 Group 3 고정익 VTOL 플랫폼이다.

## 주요 특징

| 항목 | 사양 |
|------|------|
| **분류** | Group 3 고정익 VTOL |
| **ITAR** | ITAR-free (수출 통제 면제) |
| **원산지** | 비중국산 |
| **임무** | 장시간 정찰/감시(ISR) |
| **페이로드** | 중량 페이로드 유연성 |
| **운용 비용** | 감소된 운용 비용 |

## 시장 의의

- **수출 통제 우회**: ITAR-free로 미국 외 수출 용이
- **공급망 다각화**: 중국 의존도 없는 대안
- **방산 시장**: 군용 ISR 임무에 적합
