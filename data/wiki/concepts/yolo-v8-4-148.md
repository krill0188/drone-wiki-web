# YOLO v8.4.148 Release

**버전**: v8.4.148
**릴리스일**: 2026-09-11
**분류**: SAM 3.1 이미지 예측 체크포인트 정식 지원

## 핵심 변경사항

- **SAM 3.1 체크포인트 지원** — 체크포인트 키 매핑을 추가해 `sam3.1_multiplex.pt`가 `SAM`·
  `SAM3Predictor`와 올바르게 동작. 기존에는 SAM 3.1의 prompt encoder, mask decoder, embedding,
  neck이 조용히 랜덤 초기화된 가중치로 실행되던 문제를 수정. 기존 `sam3.pt` 체크포인트는 그대로
  호환.
- **지원되는 SAM 3.1 예측 워크플로** — `SAM`/`SAM3Predictor`를 통한 포인트·박스 프롬프트,
  `SAM3SemanticPredictor`를 통한 텍스트·이미지 예시(exemplar) 프롬프트. 신규 Object Multiplex
  메모리 아키텍처 기반 SAM 3.1 비디오 트래킹은 아직 미포팅 — 비디오 워크플로는 기존 `sam3.pt` +
  SAM 3 비디오 예측기 사용 권장.
- **문서 갱신** — SAM 3.1 가이드, 지원 범위, 벤치마크 비교, 게이트된 가중치 다운로드 절차 추가.
  모델 인덱스에 `sam3.1_multiplex.pt` 등재.
- **저장소 가이드 개선** — 루트 `AGENTS.md` 축약, 문서 전용 지침을 신규 `docs/AGENTS.md`로 이동.
- **버전 갱신**: 8.4.147 → 8.4.148.

## 영향

SAM 3.1 이미지 예측기가 랜덤 초기화 대신 실제 학습된 체크포인트 구성요소를 사용하게 되어 세그멘
테이션 결과가 정확해짐. SAM 3.1 가중치는 Meta에서 게이트 처리되어 있어 Hugging Face의 승인된
모델 페이지를 통해서만 획득 가능. 비디오 트래킹(Object Multiplex)은 아직 미지원이므로 드론 온보드
영상 추적 파이프라인은 기존 SAM 3 경로를 유지해야 함.
