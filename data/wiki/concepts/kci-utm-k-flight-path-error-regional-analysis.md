# 다양한 지역 환경에서의 UTM-K 기반 드론 비행경로 오차 분석

정재호(연암공과대학교 기계공학과)가 한국산학기술학회논문지(2026)에 발표한 연구로, 공주·여수·
울주·통영·포천 5개 지역의 지자체 드론 배송 실증 데이터를 활용해 UTM-K 기반 비행경로 오차 분석
방법론의 일반화 가능성을 검토했다. 원문은 비공개(페이월)이며 초록만 확인
가능하다.^[inbox/processed/fetch-2026-10-02-kci-다양한-지역-환경에서의-utm-k-기반-드론-비행경로-오차-분석.md]

## 방법

- GPS 기반 비행 데이터를 **UTM-K 직교좌표계**로 변환.
- 계획 비행경로와 실제 비행경로 간 거리 편차, 그리고 기준 경로와 드론 실시간 위치 사이의
  최단거리로 비행경로 오차를 정량 산출.
- 분석 대상 지역은 도심·도서·해안·산간 등 서로 다른 운용 환경을 포함.

## 결과

- 모든 실증 구간에서 비행 경로가 한국교통안전공단의 드론 배송 실증사업 안전 기준을 만족.
- 경로 오차율도 허용 범위 이내로 유지됨.
- UTM-K 기반 분석 방법이 다양한 지역 환경에서도 안정적으로 적용 가능함을 확인 — 향후 드론 배송
  상용화 및 K-UAM 기반 물류 시스템 구축의 기초자료로 제시.
