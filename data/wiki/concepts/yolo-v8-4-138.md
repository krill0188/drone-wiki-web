# YOLO v8.4.138 Release

**버전**: v8.4.138  
**릴리스일**: 2026-09-01  
**분류**: 안정성 중점 릴리스 (stability-focused)

## 핵심 변경사항

- **구형 체크포인트 로딩 복구** — v8.4.95 이전에 저장된 detection/classification/pose/segmentation/OBB/keypoint 체크포인트를 재훈련 없이 로딩 가능.
- **YOLO-World 로딩 수정** — YOLO-World 모델 및 관련 체크포인트 패키지 로딩 오류 해결.
- **MuSGD + `channels_last` 충돌 수정** — 텐서 flatten 연산을 레이아웃 안전한 방식으로 교체, CUDA 훈련 안정성 향상.
- **SAM 피처 추출 최적화** — SAM/SAM2/SAM3 이미지 임베딩을 inference 모드에서 계산, 불필요한 autograd 그래프 제거 → 반복 추론 시 메모리 절감.
- **분산 훈련(DDP) 강건성** — 미니 배치에 할당 타겟 없을 때 DDP 실패 방지; detection/pose/OBB 브랜치의 학습 그래프 연결 유지.
- **Tuning 결과 수정** — 다중 데이터셋 튜닝에서 데이터셋 이름·순서 보존; 실패 데이터셋은 0으로 기록하여 fitness 플롯 일관성 유지.
- **분류 추론 전처리 개선** — 전처리 작업을 추론 장치에서 배치 단위로 처리, CPU 오버헤드 감소 및 처리량 향상.
- **BoT-SORT 추적 속도 향상** — global motion compensation 코너 검출 상한 1000→400점으로 축소, optical-flow 연산 감소.
- **정밀도/양자화 문서 개선** — `quantize` 파라미터가 포맷별로 다른 런타임 정밀도(FP16/FP32/INT8)를 선택함을 명시.

## 영향

체크포인트 호환성이 v8.4.95 이전으로 확장되어 기존 모델 자산 재사용성이 높아졌다. YOLO-World 사용자, MuSGD 훈련 환경, 멀티-GPU 분산 훈련 파이프라인에서 즉각적인 안정성 이점을 얻을 수 있다. 드론 탐지 모델에 흔히 사용하는 BoT-SORT 추적의 경우 속도 향상이 실시간 임베디드 추론에 유리하다.
