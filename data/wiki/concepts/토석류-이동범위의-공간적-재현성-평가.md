# 토석류 이동범위의 공간적 재현성 평가

2023년 경북 예천군 벌방리 토석류 발생 사건을 대상으로, UAV 관측자료와 Random Walk Model(RWM)을 결합하여 토석류 이동범위를 정량적으로 재현평가하는 연구 방법론입니다. UAV를 통해 확인된 실제 발생지점을 RWM의 방출 위치로 적용하여 발생 위치 불확실성을 최소화했으며, IoU 및 F1-score 등 공간적 일치도 지표를 통해 모의 범위와 실제 관측 범위의 일치도를 분석했습니다.

## 개요

본 연구는 UAV 기반 항공 사진 측량 자료를 활용하여 토석류 이동 경로와 범위를 파악하고, 이를 Random Walk 기반 모의 모델과 비교 검증하는 과정을 다룹니다. 5개의 실제 토석류 발생지점을 RWM의 방출 위치로 설정하고, 10m 격자 기준 103회와 104회의 Random Walk 시뮬레이션을 수행하여 계산 안정성을 검토했습니다. 이동성 매개변수(θ)와 정규화 영향빈도(NIF) 임계값에 대한 민감도 분석을 통해 최적 조건(θ = 9°, NIF = 0.125)을 도출했으며, 해당 조건에서 UAV 관측범위(0.0931 km²) 대비 RWM 모의범위(0.1321 km²)가 약 41.9% 넓게 나타나는 공간적 과대모의 경향이 확인되었습니다. 시뮬레이션 횟수를 10³에서 10⁴로 늘렸을 때 IoU와 F1-score 변화는 미미했으나 계산시간은 약 8.5배 증가한 것으로 나타났습니다.

## 핵심 파라미터

| 매개변수 | 값 | 비고 |
| :---: | :---: | --- |
| Random Walk 횟수 | 10³ ~ 10⁴ | IoU/F1-score 변화 최소, 계산시간 8.5배 증가 |
| 이동성 매개변수 (θ) | 9° | 가장 높은 공간적 일치도 조건 |
| 정규화 영향빈도 (NIF) | 0.125 | 가장 높은 공간적 일치도 조건 |
| UAV 관측 범위 | 0.0931 km² | - |
| RWM 모의 범위 | 0.1321 km² | 관측면적 대비 41.9% 커서 과대모의 |
| Precision | 0.440 | - |
| Recall | 0.624 | - |
| F1-score | 0.516 | - |
| IoU | 0.348 | - |

## 활용처

- 재난 현장 후속 조치 및 토석류 위험 구역 산정을 위한 공간 재현성 검증
- UAV 관측 데이터의 모델링 신뢰도 평가
- 재난 대비 및 위험 구역 매핑을 위한 Random Walk 모델 파라미터 튜닝
