# YOLO v8.4.156 Release

2026-09-19 릴리스. 원격 NDJSON 데이터셋 변환의 신뢰성을 높이고, INT8 TensorRT export를
더 빠르게 하면서 정확도를 유지하는 데 초점을 맞췄다.^[raw/articles/fetch-2026-09-20-yolo.md]

## 주요 변경사항

- **원격 NDJSON 변환 신뢰성(PR #26242)**: 기존 변환 락 안에서 원격 NDJSON 매니페스트를
  새로 갱신해 오래된 매니페스트가 조용히 재사용되는 문제를 방지. URL이 다른 동명
  매니페스트끼리 덮어쓰지 않도록 전용 임시 다운로드 디렉터리를 사용한다. 정규화된 콘텐츠
  해시를 변환 캐시로 유지하므로, 서명 URL이 바뀌어도 내용이 같으면 기존 라벨/이미지를
  재사용하고 매니페스트가 바뀌면 새 데이터셋 디렉터리를 만들어 진행 중인 학습 파일을 보존한다.
  일반 `check_file` 유틸리티에서 NDJSON 전용 삭제 동작도 제거됐다.
- **INT8 TensorRT export 개선(PR #26171)**: QAT가 모델 헤드를 더 많이 양자화하되 정확도에
  민감한 최종 출력 레이어와 DFL 연산은 부동소수점으로 유지. BatchNorm을 export/예측/검증
  시 융합하고 융합에 맞춰 양자화 범위를 조정해 INT8 값이 사실상 동일하게 유지된다. PTQ
  export도 민감한 헤드 연산을 INT8에서 제외하고 적절히 FP16을 사용하며, 신·구 TensorRT
  버전별 정밀도 처리를 정비했다.
- **테스트 견고성(PR #26217)**: 제한적 로드 모델 테스트가 하드웨어 백엔드 간 비트 단위
  일치 대신 허용 오차 비교를 사용해 오탐 실패를 줄인다.
- **유지보수/문서**: 셀프호스트 GitHub Actions 정리 러너 v1.4.39 → v1.4.40, Security
  Alarm System 가이드 영상 갱신, export 문서에 QAT 헤드 동작 설명 추가.

## 영향

원격 데이터셋 갱신 시 오래된 데이터로 학습하는 실수가 줄고, 동일 데이터셋의 불필요한
다운로드가 감소한다. Jetson 등 TensorRT 기반 엣지 배포에서 INT8 엔진의 속도와 정확도
균형이 개선될 것으로 기대된다(드론 탑재 검출 파이프라인 관점의 해석).

## 한계

요약은 확인되지 않았다.
