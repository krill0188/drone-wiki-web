# YOLO v8.4.166 Release

2026-09-29 릴리스. 모델 아키텍처 변경 없이 데이터셋 처리와 예측 출력 신뢰성, Platform/추론
문서를 개선한 유지보수 릴리스다.^[inbox/processed/fetch-2026-09-30-yolo.md]

## 주요 변경사항

- **시맨틱 마스크·데이터셋 변환**: Pascal VOC 스타일 팔레트 PNG 마스크의 클래스 ID를 보존하고,
  16비트 마스크의 픽셀 값을 유지. 구버전 시맨틱 마스크 캐시를 재구성하며, 어노테이션이 없는
  LVIS 이미지도 포함하도록 수정.
- **세그멘테이션 정확도**: 검증 중 리사이즈된 인스턴스 마스크가 축소되는 문제를 방지하고, 시맨틱
  예측 저장 시 올바른 letterbox 크롭을 유지.
- **데이터셋·학습 신뢰성**: 오래된 디스크 캐시 이미지, 예측 소스 목록의 상대 경로/글롭, 오래된
  분류 분할 복사본, 안전하지 않은 소형 이미지 학습 설정 문제를 수정.
- **이미지/영상 처리**: 어노테이션 시각화와 이미지 압축이 EXIF 방향을 반영하며, 프레임이
  건너뛰어져도 저장된 영상의 길이가 예상과 일치하도록 수정.
- **문서 갱신**: Rust 추론 0.0.50 기준 디바이스 선택·영상 요구사항·GPU 전처리·RT-DETR 지원 등
  추론 가이드 갱신, Platform 문서도 최신 어노테이션/데이터셋/추론/배포 동작 반영.

## 영향

팔레트/16비트 마스크가 잘못 거부되거나 클래스 ID가 잘못 해석될 가능성이 줄고, 검증 마스크와
저장된 예측이 원본 이미지 크기·내용과 더 잘 일치한다. 데이터셋 로딩·학습 점검·예측 입력의
일관성이 높아져 문제를 더 이른 단계에서 포착한다.
