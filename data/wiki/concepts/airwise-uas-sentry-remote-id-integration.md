# Airwise Solutions × UAS Sentry — Remote ID 탐지 통합

Airwise Solutions와 UAS Sentry가 저고도 공역 인식(low-altitude airspace
awareness)에 초점을 맞춘 파트너십을 체결했다. UAS Sentry Nexus의 탐지
기능을 Airwise Nexus 플랫폼에 통합해 탐지된 Remote ID 신호를 공항·전력·
에너지 등 중요기반시설 운영자와 공공안전·기업 사용자를 위한 공통
작전상황도(common operating picture)에 함께 표시한다.^[inbox/fetch-2026-09-17-rss-dronelife.md]^[inbox/fetch-2026-09-17-rss-dronedj.md]
