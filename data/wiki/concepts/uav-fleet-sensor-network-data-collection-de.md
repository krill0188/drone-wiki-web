# UAV 팀의 분산 센서망 데이터 수집 계획

**출처**: arXiv 2101.03693 (2021-01-11), 초록 기준.

환경 감시·기상·농업·재생에너지에 쓰는 대규모 분산 센서망의 데이터를 UAV 팀이 협업 수집하는 미션 플래너다. 페이로드와 배터리 용량 제약을 고려하고, Differential Evolution(DE) 최적화로 센서 우선순위를 반영하면서 중복 수집을 피해 방문 센서 수를 최대화한다. 광범위한 시뮬레이션과 비교 분석으로 효과를 확인했다.^[inbox/processed/fetch-2026-10-20-arxiv-exploiting-a-fleet-of-uavs-for-monitoring-and-data-acquisiti.md]
