# YOLO v8.4.184 Release

**버전**: v8.4.184
**릴리스일**: 2026-10-22
**분류**: 신뢰성 중심 릴리스 — 다중 페이지 TIFF 처리 수정, 모델 로딩·검증 개선 (새 모델 아키텍처 없음)

이전 기록은 [[yolo-v8-4-183]], 프레임워크 개요는 [[yolo]] 참조.

## 핵심 변경사항
- **다중 페이지 TIFF**: 그레이스케일 TIFF는 기본적으로 첫 페이지만 로드한다. 이전에는 여러 페이지가 이미지 채널로 합쳐졌다. 같은 크기 페이지를 쌓는 동작은 `cv2.IMREAD_UNCHANGED`일 때만 유지되어 멀티스펙트럴 워크플로는 보존된다.^[inbox/processed/fetch-2026-10-23-yolo.md]
- **YOLOE·YOLO-World 로딩**: 체크포인트 유형으로 올바른 모델 래퍼를 고르므로 `best.pt` 같은 일반 파일명으로 저장해도 동작한다. 텍스트 융합 YOLOE의 클래스명을 바꾸면 조용히 라벨이 바뀌지 않고 명확한 오류를 낸다.^[inbox/processed/fetch-2026-10-23-yolo.md]
- **SAM 마스크 정제**: 부동소수점 프롬프트 마스크의 음수·소수 값을 유지한다.^[inbox/processed/fetch-2026-10-23-yolo.md]
- **데이터·지표**: 다중 파트 폴리곤 연결, 혼동행렬 매칭, 직사각형 크기 분류 예측, 라벨 없는 데이터셋 검증을 고쳤고 쿼리 문자열이 붙은 아카이브 URL도 인식한다.^[inbox/processed/fetch-2026-10-23-yolo.md]
- **통합**: Weights & Biases가 사용자가 시작한 run 안에서의 학습을 지원하고, Platform 학습 재개와 OpenVINO/LiteRT 장치 처리가 개선됐다.^[inbox/processed/fetch-2026-10-23-yolo.md]

## 드론 관점
항공 멀티스펙트럴 영상은 `cv2.IMREAD_UNCHANGED`로 읽어야 페이지가 밴드로 유지된다는 점이 영향 포인트다. 드론 전용 수치는 릴리스 노트에 없다. 관련: [[computer-vision-drone]], [[companion-computer]].
