# YOLO v8.4.137

YOLO v8.4.137은 PyTorch 1.11+ CUDA 훈련 시 channels-last 메모리 레이아웃을 자동으로 활성화하여 GPU 훈련 성능을 향상시킨 릴리스이다.

## 주요 변경사항

### Automatic channels-last training

- `channels_last=None` 설정이 CUDA 훈련에서 **PyTorch 1.11 이상** 환경에서 자동으로 NHWC 메모리 포맷을 사용
- 명시적 제어 옵션:
  - `channels_last=None`: 지원되는 경우 자동으로 channels-last 선택
  - `channels_last=False`: 전통적인 NCHW 포맷 유지
  - `channels_last=True`: channels-last 명시적 요청

### 안전한 호환성 동작

- PyTorch 1.10 이하, CPU, MPS 훈련은 기본적으로 NCHW 사용
- resume 처리 개선: `channels_last` 설정이 훈련 재개 시 업데이트 가능한 옵션에 포함

## 성능 영향

- ⚡ **잠재적 CUDA 훈련 속도 향상**: 호환 가능한 GPU(특히 최신 Tensor Core 하드웨어)에서 컨볼루션 성능 개선
- 🧠 **더 나은 YOLO26 훈련 기본값**: 지원되는 PyTorch 및 CUDA 환경에서 수동 최적화 활성화 불필요
- 🛡️ **감소된 호환성 위험**: PyTorch 1.11부터 자동 활성화되어 알려진 channels-last 실패 방지

## 검증 범위

- CUDA 11.1–13.2
- PyTorch 1.8–2.12
- Python 3.8–3.13
- 다양한 최신 NVIDIA GPU
