# DGE-YOLO: Dual-Branch Gathering and Attention for UAV Detection

DGE-YOLO is an enhanced YOLO-based detection framework designed for multi-modal UAV object detection, combining infrared and visible imagery with efficient multi-scale attention mechanisms.

## Architecture

### Dual-Branch Design
- Separate branches for infrared and visible image processing
- Modality-specific feature extraction
- Enhanced small object detection capabilities

### Efficient Multi-scale Attention (EMA)
- Spatial-scale feature enhancement
- Improved semantic representation
- Better handling of complex aerial scenarios

### Gather-and-Distribute (GD) Module
- Replaces conventional neck architecture
- Mitigates information loss during feature aggregation
- Optimized for UAV detection tasks

## Performance

- **Dataset**: DroneVehicle
- Superior performance over state-of-the-art methods
- Effective in multi-modal UAV detection tasks

## Key Innovations

1. **Dual-branch architecture** for modality-specific processing
2. **EMA mechanism** for multi-scale feature learning
3. **GD module** for improved information aggregation
