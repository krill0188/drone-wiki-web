# YOLO v8.4.195 Release

**버전**: v8.4.195 · **릴리스일**: 2026-10-31 · **분류**: Python 3.15 사전 호환 점검, AutoBatch 프로파일링 수정, 문서 정비 릴리스.^[inbox/processed/fetch-2026-11-01-yolo.md]

## 핵심 변경사항
- **Python 3.15 CI** — Linux/Python 3.15 테스트 잡과 패키지 classifier를 추가했다. ONNX Runtime·OpenVINO가 아직 Python 3.15 wheel을 제공하지 않아 축소된 extras만 설치하고 해당 export 테스트는 건너뛴다.
- **AutoBatch 호환성 수정** — 프로파일링에서 FLOPs를 세는 시점을 시간 측정 패스 이후로 옮겨, 구버전 PyTorch에서 gradient 관련 실패(NVIDIA Jetson에서 관찰된 실패 포함)를 피한다.
- **문서 정비** — 301개 Markdown 파일의 세부 내용과 관련 가이드·모델·데이터셋 링크를 정리했다.

## 영향
릴리스 노트는 주요 모델·아키텍처 변경이 없다고 밝힌다. Jetson 등 구버전 PyTorch 환경의 AutoBatch 안정성이 개선된다. 단일 릴리스 노트 기준이다.
