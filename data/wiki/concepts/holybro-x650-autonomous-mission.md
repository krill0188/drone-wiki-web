# HolyBro X650 Autonomous Mission Planning with ArduPilot

Guide to planning and flying autonomous missions using the HolyBro X650 build with ArduPilot and PixHawk 6C flight controller.

## Mission Planning Basics

### What is a Mission?
- Pre-programmed flight path with waypoints
- Automated execution without manual control
- Safety checks and altitude verification

### Mission Components
- Waypoint definition
- Altitude and distance parameters
- Safety boundaries
- RTL (Return to Launch) configuration

## Monitoring and Safety

### Telemetry Monitoring
- Radio or telemetry radios for real-time monitoring
- Ground Control Station (GCS) integration
- Mission progress tracking

### Safety Checks
- Distance verification
- Altitude limits
- Geofence boundaries
- Battery and failsafe settings

## Mission Execution

### Starting a Mission
- Pre-flight safety verification
- Mission upload to flight controller
- Auto mode activation

### Cancel and Restart
- Default behavior on mission interruption
- Resume from last waypoint options
- Manual override procedures
