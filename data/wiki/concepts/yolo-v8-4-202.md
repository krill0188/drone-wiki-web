# YOLO v8.4.202 릴리스 (2026-11-04)

Ultralytics 공식 GitHub 릴리스 노트(v8.4.202, 2026-11-04) 기준 요약이다.^[inbox/fetch-2026-11-05-yolo.md]

## 🌟 요약
스트림 비디오 저장 개선과 여러 호환성·신뢰성 이슈 수정, 모델·벤치마크 문서 업데이트.

## 📊 주요 변경사항
- **스트림 예측 저장 프레임 레이트 수정**: RTSP 스트림, 웹캠, `.streams` 소스가 각 스트림의 실제 FPS를 사용(멀티 스트림 설정 포함). 종전 30 FPS 가정 제거. 비디오 파일·화면 캡처 레이트는 그대로.
- **모델 로딩·내보내기 호환성 개선**: MNN 내보내기가 태스크 메타데이터를 로드 전 노출하여, 이름이 바뀐 pose/segmentation/classification/OBB 모델과 RT-DETR 내보내기가 올바르게 식별됨. 클래스명 가중치 리매핑이 CPU 체크포인트를 GPU 모델에 로드할 때도 작동.
- **TensorRT INT8 내보내기 신뢰성 향상(구형 GPU)**: T4 등 SM 7.5 GPU에서 동적 INT8 빌드 시 더 안전한 최소 입력 크기 사용하여 소형 입력 빌드 실패 방지.
- **데이터셋·Platform 동작 명확화**: 분류 검증 시 `val`/`test` 스플릿이 둘 다 없으면 유용한 에러 메시지 출력. Platform 학습 인자를 JSON 값으로 전송(문자열 변환 제거).
- **YOLO27·벤치마크 문서 업데이트**: YOLO27 결과, 모델 세부사항, FLOPs 보고 수정. VisDrone, HIT-UAV의 무시 영역(ignored regions) 반영해 벤치마크 점수 재계산.

## 🎯 목적·영향
- ✅ 스트림 녹화가 올바른 속도로 재생(서로 다른 프레임 레이트, 프레임 스킵 포함).
- ✅ 메타데이터, 디바이스, 구형 GPU INT8 제한으로 인한 모델 로딩·배포 실패 감소.
- ✅ 데이터셋 설정 이슈 진단 용이, Platform에 더 유용하고 올바르게 타입화된 학습 설정 전달.
- 📖 문서 정정으로 더 정확한 성능 비교와 명확한 평가 세부사항 제공(모델 자체 변경 아님).
