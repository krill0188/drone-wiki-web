# YOLO v8.4.176 Release

**버전**: v8.4.176
**릴리스일**: 2026-10-12
**분류**: YOLO-World 체크포인트 경량화 + 검증/미세조정 신뢰성 + SAM·배포 경로 수정

## 핵심 변경사항

- **YOLO-World 체크포인트 대폭 축소** — 클래스를 설정해도 기본적으로 CLIP 텍스트 인코더를 캐시하지 않는다. `yolov8s-worldv2.pt` 저장본이 328.5 MB에서 25.8 MB로 줄었고, 다시 불러와도 예측은 동일했다. 명시적으로 요청하면 캐싱은 여전히 가능하다.^[inbox/processed/fetch-2026-10-13-yolo.md]
- **검증·미세조정 신뢰성** — 검출 검증이 예측을 신뢰도 순서로 적격 타깃에 매칭해 누락 매칭을 줄인다. YOLOE 미세조정·resume 시 학습된 분류 헤드를 재초기화하지 않고 보존한다.^[inbox/processed/fetch-2026-10-13-yolo.md]
- **세그멘테이션/SAM 수정** — MobileSAM FP16 추론의 빈 마스크 문제 해결, 재사용되는 SAM predictor가 새 이미지·영상에서 상태를 초기화한다. YOLO26 세그멘테이션 mAP를 떨어뜨린 마스크 임계값 변경은 되돌렸다.^[inbox/processed/fetch-2026-10-13-yolo.md]
- **배포·입력 처리** — ONNX GPU 추론이 사용자 지정 입력 이름과 strided 텐서를 지원하고, OpenVINO NPU 추론은 배치·depth 출력을 더 안정적으로 처리한다. 부동소수점 NumPy 이미지가 그레이스케일 모델에서도 동작한다.^[inbox/processed/fetch-2026-10-13-yolo.md]
- **영상·추적·벤치마크** — 저장 영상이 소수점 프레임레이트를 유지하고, 고 FPS 스트림 처리 및 신규 Python에서의 tracker 복사/pickle이 정상화되었다. 벤치마크 워크플로 문제도 수정되었다.^[inbox/processed/fetch-2026-10-13-yolo.md]
- **문서/Platform** — 미세조정·추론·정밀도 동작 문서 보강, Platform 문서에 관련도순 데이터셋 정렬·AI 지원 모델 비교 추가.^[inbox/processed/fetch-2026-10-13-yolo.md]

원문은 변경 PR 목록 중간에서 절단되어 있어 나머지 PR은 확인되지 않았다.

## 영향

드론 온보드·엣지 환경에서 사용자 정의 어휘 YOLO-World 모델을 배포할 때 체크포인트 크기 부담이 크게 줄고, 검증 지표와 YOLOE 재학습의 신뢰도가 개선된다. 직전 릴리스는 [[yolo-v8-4-175]], 아키텍처 개요는 [[yolo]] 참조.
