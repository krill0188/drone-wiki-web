# YOLO v8.4.120

Ultralytics YOLO v8.4.120 릴리스 (2026-08-13). CUDA 학습 결정론 및 TensorFlow 내보기 안정성 개선, LLM 워크플로우 문서 확장.

## 주요 변경사항

### CUDA Anchor 생성 결정론 개선
- `cumsum_cuda_kernel` 경고 제거
- TorchScript/추적 GPU 모델의 런타임 디바이스 처리 보존

### TensorFlow 내보기 안정성
- 오래된 NVIDIA 패키지 인덱스 제거
- `onnx-graphsurgeon` PyPI 직접 설치 지원

### LLM 문서화
- OpenAI 호환 `LLM` 인터페이스 문서화
- DeepSeek, Kimi, Z.AI GLM, OpenRouter 예제 제공
- 기본 모델 `gpt-5.6-luna`로 업데이트

### Agent Skills 통합 가이드
- `ultralytics/skills` 저장소 문서화
- Claude Code, Codex 등 AI 에이전트 설치 가이드
