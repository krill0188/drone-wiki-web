# YOLO v8.4.177 Release

**버전**: v8.4.177
**릴리스일**: 2026-10-13
**분류**: SAM 프롬프트 일관성 + 내보내기·학습 재개·예측 입력 신뢰성 (신규 모델 아키텍처 없음)

이전 버전은 [[yolo-v8-4-176]], 프레임워크 개요는 [[yolo]] 참조. 원문 PR 목록이 중간에서 절단되어 있다.

## 핵심 변경사항
- **SAM 프롬프트 유지**: 디렉터리·비디오에 준 프롬프트가 첫 이미지/프레임뿐 아니라 모든 항목에 적용된다. 프롬프트 좌표 스케일링 시 호출자의 NumPy 배열·텐서를 변경하지 않는다.^[inbox/processed/fetch-2026-10-14-yolo.md]
- **내보내기·추론**: Intel NPU는 고정 입력 크기가 필요해 동적 OpenVINO 내보내기를 요청한 이미지 크기로 고정한다. 출력 shape에 심볼릭 차원이 있는 ONNX GPU 추론은 호환 실행 경로로 폴백한다.^[inbox/processed/fetch-2026-10-14-yolo.md]
- **학습·체크포인트**: 짧은 학습도 최소 한 번 옵티마이저 스텝을 수행한다. RMSprop 체크포인트가 작은 gradient 이력 값을 보존해 재개 시 큰 업데이트가 튀는 것을 막는다.^[inbox/processed/fetch-2026-10-14-yolo.md]
- **예측 입력**: PIL 이미지의 EXIF 방향을 반영하고, `http`로 시작하는 로컬 경로를 URL로 오인하지 않는다.^[inbox/processed/fetch-2026-10-14-yolo.md]
- **연동·문서**: 학습 실행마다 integration 설정을 읽고, W&B 최종 플롯·오프라인 재개 ID·정리 동작을 수정했다. CI 알림 중앙화 등 워크플로 변경 포함.^[inbox/processed/fetch-2026-10-14-yolo.md]

## 드론 관점
엣지 배포(Intel NPU·ONNX)와 탑재 영상 폴더/비디오 단위 분할에 영향이 있다. 관련: [[computer-vision-drone]].
