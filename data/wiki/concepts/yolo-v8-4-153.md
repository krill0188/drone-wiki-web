# YOLO v8.4.153 Release

2026-09-15 릴리스. SAM3 초기화 관련 치명적 버그 수정, 검증(validation) 신뢰성
개선, INT8 export 동작 명확화, Ultralytics Platform 주석/과금 문서 확장.^[inbox/fetch-2026-09-16-yolo.md]

## 주요 변경사항

- **SAM3 `compile=False` 처리 수정(PR #26189)**: predictor 옵션을 SAM3 빌더에
  전달하기 전 올바르게 변환(`False`=컴파일 비활성화, `True`=기본 컴파일 모드,
  명시적 모드 문자열은 그대로 보존). PyTorch 2.14 Dynamo 오류를 유발하던 의도치
  않은 `torch.compile` 활성화 방지. 6종 Platform SAM 모델 전체에서 HTTP/WebSocket
  추론 검증 완료.
- **독립 실행형(standalone) 시맨틱 분할 검증 개선**: 폴리곤 기반 시맨틱 데이터셋이
  데이터셋 구성 시 배경 클래스 메타데이터를 받도록 수정 — 배경 픽셀이 마지막 실제
  클래스로 잘못 배정되는 문제 방지, mIoU·픽셀 정확도 지표 정상화.
- **추가 클래스가 있는 분류 검증 수정**: 체크포인트 클래스 범위를 벗어난 샘플을
  훈련 동작과 동일하게 필터링 — `IndexError` 크래시 방지, 스킵된 샘플/클래스
  불일치에 대한 경고 명확화.
- **재개(resume) 훈련 시 명시적 데이터셋 보존**: `train(resume=True, data="...")`가
  체크포인트의 원본 데이터셋 대신 사용자가 지정한 데이터셋을 올바르게 사용.
- **INT8 export 동작·문서 개선**: QAT 체크포인트가 보정 데이터 없이 저장된 INT8
  범위를 ONNX/TensorRT로 export 가능. RKNN INT8 검증은 탐지 모델에만 적용되도록
  수정. TensorRT 문서에서 INT8 export 시 `dynamic` 자동 활성화 주장 제거.
- **IMX export 시 `conf=0.0` 보존**: 명시적 0 신뢰도 임계값이 `0.001`로 대체되지
  않도록 수정.
- **Platform 주석/과금 문서 확장**: 데이터셋 전체 배치 주석, 클래스 매핑, 진행률
  추적, 실행 중지, 버전 스냅샷, 과금 관련 문서 추가. YOLO 스마트 주석에 pose
  데이터셋 지원 추가.
