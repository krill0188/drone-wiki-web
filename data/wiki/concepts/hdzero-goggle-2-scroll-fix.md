# HDZero Goggle 2 Scroll Wheel Fix

## 문제 증상

- 스크롤 휠이 비정상적으로 작동
- 메뉴 탐색 시 오작동

## 해결 방법

### 펌웨어 업데이트 (권장)

1. HDZero 펌웨어 다운로드: https://www.hd-zero.com/document
2. 스크롤 휠 관련 펌웨어 수정 적용
3. **하드웨어 개조 불필요**: 고글을 열지 않고도 해결 가능

### 주요 수정사항

- 스크롤 휠 입력 처리 로직 개선
- UI 탐색 안정성 향상
