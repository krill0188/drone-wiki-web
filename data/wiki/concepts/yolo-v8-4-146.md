# YOLO v8.4.146 Release

**버전**: v8.4.146
**릴리스일**: 2026-09-09
**분류**: RT-DETR 신뢰성 개선 + 익스포트 이식성·Windows 훈련 동작·GPU 컨테이너 환경 갱신

## 핵심 변경사항

- **RT-DETR 추론 안정화** — 작은 입력 이미지에서 설정된 쿼리 수보다 앵커가 적게 생성되어 발생하는
  실패 방지. 쿼리 수·디노이징 마스크·학습된 쿼리 임베딩 일관성 유지. 동적 ONNX/OpenVINO 익스포트에서
  올바른 검출 한계값 보존. TrackTrack과의 RT-DETR 트래킹 호환성 확보(미지원 NMS 복구 인자 회피).
  32~640px 이미지 크기, TorchScript/CoreML/ONNX/OpenVINO, 훈련·검증·트래킹 전반에서 검증.
- **디바이스 독립적 TorchScript 익스포트** — 익스포트 시점 텐서 생성에서 하드코딩된 디바이스 가정
  제거. CUDA/Apple MPS에서 익스포트한 TorchScript 모델을 CPU 등 다른 디바이스에서 로드·사용 가능.
  익스포트 크기와 다른 크기에서도 RT-DETR 동적 익스포트 바운딩 박스가 올바르게 유지되도록 수정.
- **FP16 임베디드 NMS 추론 개선** — end-to-end NMS 출력 행을 float32로 변환, 세그멘테이션·포즈·OBB
  FP16 익스포트의 마스크/박스 처리 실패 방지.
- **Windows CUDA 훈련 기본값 조정** — Windows에서 성능을 저하시킬 수 있는 `channels_last` 자동
  활성화 중단(명시적으로 `channels_last=True` 설정 시에는 여전히 사용 가능).
- **NDJSON 이미지 다운로드 신뢰성 향상** — 기존 30초 총 타임아웃을 연결·소켓 비활성 타임아웃으로
  대체, 느리거나 공유된 연결에서 대용량 이미지 다운로드 실패 가능성 축소.
- **GPU/익스포트 환경 갱신** — AMD64 GPU 이미지 PyTorch 2.14 + CUDA 13.2로 전환, NVIDIA ARM64
  이미지는 NVIDIA PyTorch 26.08 + CUDA 13.4 + 최신 ONNX Runtime GPU로 이동, GPU 러너에 `g++`·
  CUDA 13용 TensorRT 추가, Conda 빌드는 PyTorch 2.13/torchvision 0.28/CUDA 13.0 사용.
- **CI/유지보수** — GPU CI 워크플로 복원(임시 비활성 조건 유지), 격리 익스포트 설정 전 디스크
  정리 추가, CUDA 13/JetPack/TensorRT/DLA/Conda 이미지·익스포트 호환성 문서 갱신. 버전 8.4.145 →
  8.4.146.

## 영향

RT-DETR 기반 파이프라인의 소형·동적 입력 처리 안정성이 향상되어, 드론 탑재 실시간 검출에서 흔한
저해상도·가변 입력 크기 시나리오의 추론 실패 위험이 줄어든다. 익스포트 디바이스 이식성 개선으로
훈련용 GPU와 배포용 엣지 디바이스가 다른 드론 온보드 파이프라인 운용이 더 안정적이다.
