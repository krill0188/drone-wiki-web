# YOLO v8.4.146 Release

**버전**: v8.4.146
**릴리스일**: 2026-09-09
**분류**: RT-DETR 추론 안정성, 내보내기 이식성, Windows 훈련 기본값, GPU/내보내기 환경 업데이트

## 핵심 변경사항

- **RT-DETR 추론 안정성**: 작은 입력 이미지가 설정된 쿼리 수보다 적은 앵커를 생성할 때 실패하던
  문제를 방지. 쿼리 수·디노이징 마스크·학습된 쿼리 임베딩의 일관성을 유지하고, 동적 ONNX/OpenVINO
  내보내기에서도 올바른 탐지 한도를 보존. TrackTrack과의 RT-DETR 추적 호환성도 확보(지원되지 않는
  NMS 복구 인자 회피). 32~640픽셀 이미지 크기, TorchScript/CoreML/ONNX/OpenVINO, 훈련·검증·추적
  전반에서 검증됨.
- **디바이스 독립적 TorchScript 내보내기**: 내보내기 시점 텐서 생성에서 하드코딩된 디바이스 가정을
  제거해, CUDA나 Apple MPS에서 내보낸 TorchScript 모델을 CPU 등 다른 디바이스에서도 로드·사용
  가능. 동적 RT-DETR 내보내기 시 내보내기 크기와 다른 크기에서도 바운딩 박스가 올바르게 유지되도록
  수정.
- **FP16 임베디드-NMS 추론 개선**: end-to-end NMS 출력 행을 float32로 변환해, 세그멘테이션·포즈·OBB
  FP16 내보내기가 마스크/박스 처리 중 실패하는 문제 방지.
- **Windows CUDA 훈련 기본값 변경**: 성능을 크게 저하시킬 수 있는 Windows 환경에서 `channels_last`
  메모리 포맷 자동 활성화를 중단(명시적으로 `channels_last=True` 설정 시 여전히 사용 가능).
- **NDJSON 이미지 다운로드 신뢰성 향상**: 기존 30초 전체 타임아웃을 연결·소켓 비활성 타임아웃으로
  대체해, 느리거나 공유된 연결에서 대용량 이미지 다운로드 실패 가능성을 낮춤.
- **GPU/내보내기 환경 업데이트**: AMD64 GPU 이미지는 PyTorch 2.14 + CUDA 13.2, NVIDIA ARM64는
  PyTorch 26.08 + CUDA 13.4로 갱신. GPU 러너 이미지에 `g++`·TensorRT(CUDA 13) 추가. LiteRT는
  PyTorch 2.14 비호환으로 Python 내보내기 이미지에 유지. Conda Docker 빌드는 conda-forge PyTorch
  2.13/torchvision 0.28/CUDA 13.0 사용.
- **CI/유지보수**: GPU CI 워크플로 복원(명시적 조건으로 임시 비활성 유지), 내보내기 격리 설정 전
  디스크 정리 추가, CUDA 13/JetPack/TensorRT/DLA/Conda 이미지 관련 문서 갱신. 8.4.145 → 8.4.146.

## 영향

RT-DETR을 작은 입력 크기나 동적 내보내기 환경에서 사용하는 드론 탑재 검출 파이프라인의 쿼리/앵커
관련 추론 실패가 줄어든다. 한 가속기에서 내보낸 모델을 다른 디바이스에서 재사용할 때의 신뢰성도
높아진다.
