# YOLO v8.4.164 Release

2026-09-27 릴리스. 모델 구조나 예측 결과 변경 없이 FLOPs 계산 효율화, export, 비디오 추론,
데이터셋 검증, 안정성을 개선했다.^[inbox/processed/fetch-2026-09-28-yolo.md]

## 주요 변경사항

- **FLOPs 계산 고속화**: THOP 2.2.0에 위임해 어텐션 연산 프로파일링 지원, YOLO11/YOLO12/YOLO26
  및 RT-DETR 같은 어텐션 기반 모델에서 전체 해상도 프로파일링 대신 더 작은 stride로 처리
  (`ultralytics-thop` 2.2.0 의존).
- **Export 효율화**: CoreML export가 중복 trace 검사를 생략해 약 2.8~3배 빨라졌고, 중복 setup
  forward pass도 제거.
- **비디오 추론 개선**: CUDA 추론이 GPU 처리 중 다음 비디오 프레임을 prefetch, 배치가 단일
  비디오 내로 유지되도록 수정해 서로 다른 프레임레이트 처리 시 FPS 혼선 문제도 해결.
- **데이터 처리 신뢰성**: 데이터셋 스캔이 잘못된 OBB 라벨과 소수점 class ID를 더 일찍 감지,
  pose 데이터셋의 detection 학습 허용, 다중 행 예측 CSV 파싱 수정.
- **버그 수정**: PIL 기반 어노테이션 메모리 증가, 조기 종료 시 예측 스트림 정리, 일반 예측에
  영향을 주던 tracker 콜백, 헤드 레이아웃이 다른 YOLOv9 distillation 문제 수정.

## 영향

`model.info()`나 학습 시작 로깅의 FLOPs 계산 부담이 줄고, export/CUDA 비디오 추론 파이프라인이
더 매끄러워지며, 데이터셋 오류를 더 이른 단계에서 명확하게 확인할 수 있다.
