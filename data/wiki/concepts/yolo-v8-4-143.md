# YOLO v8.4.143 Release

**버전**: v8.4.143
**릴리스일**: 2026-09-07
**분류**: YOLO26 INT8 양자화 인식 훈련(QAT) 도입, 배포/평가 워크플로 개선, 문서·통합 정비

## 핵심 변경사항

- **INT8 양자화 인식 훈련(QAT)** — `train` 모드에서 `quantize=8` 지원. 사전학습 가중치를 INT8
  양자화를 시뮬레이션하며 미세조정해, 배포 후 양자화 대비 정확도 손실을 줄임. 체크포인트에 보정된
  양자화 범위를 저장하고, 별도 보정 데이터 없이 Q/DQ 노드 포함 ONNX/TensorRT로 직접 export 가능.
  엣지 하드웨어에 YOLO26을 배포할 때 특히 유용.
- **검증 지표 확장** — 클래스별 AP75 값을 검증 요약·DataFrame·CSV·JSON 출력에 추가(detection,
  segmentation, pose, OBB 전 태스크 공통 적용).
- **YOLO26 배포 워크플로 개선** — DeepStream 문서가 서드파티 스크립트 대신 네이티브 Ultralytics
  exporter를 사용하도록 갱신, NMS-free 헤드(`nms=False`) 사용 시점을 명확화, Apple Core AI export
  대상 문서 추가.
- **훈련/모델 라이프사이클 버그 수정** — `reset_weights()` 이후·재개(resume)·다중 데이터셋/분산
  훈련 시 사전학습 모델 처리 오류 수정, 학습 중 Platform 모델 URI 보존, SAM3 디코더 좌표 캐시
  잔존 문제 제거.
- **플랫폼/인증 갱신** — 로그인·모델 다운로드·데이터셋 export·훈련 리소스 접근에 Ultralytics
  Platform SDK 사용.

## 영향

INT8 QAT는 리소스 제약이 큰 엣지 하드웨어에 YOLO26을 배포할 때 정확도를 더 잘 보존하면서
메모리 사용량과 추론 지연을 줄인다. 클래스별 AP75 확장은 드론 탑재 실시간 객체 검출 모델의
성능 평가 정밀도를 높인다.
