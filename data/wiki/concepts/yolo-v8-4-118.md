# YOLO v8.4.118

Ultralytics v8.4.118, released August 11, 2026, introduces a standalone OpenAI-compatible LLM interface alongside YOLO vision models, plus improvements to OBB training, dataset handling, and model reliability.

## New LLM Interface

Standalone `LLM` model interface (`from ultralytics import LLM`):

- **APIs supported**: OpenAI Responses and Chat Completions
- **Input types**: Local paths, URLs, data URLs, NumPy arrays, PIL images
- **Features**: Reusable prompts, request overrides, conversation state, API keys
- **Dependency**: Optional `openai` package
- **Independence**: Separate from Ultralytics Platform and workflow-runtime

## OBB Training Improvements

Mosaic, CutMix, and RandomPerspective now preserve OBB orientation when objects are clipped by image boundaries — preventing incorrect rotation angles during training.

## Performance Optimizations

- **CopyPaste augmentation**: Batched instance concatenation reduces overhead
- **Dataloader workers**: Correctly reset when resuming after Mosaic augmentation

## YOLOE Reliability

- Visual prompt validation before model state modification
- Flat prompts accepted for batched image sources
- Clearer errors for invalid string class labels and mismatched vocabularies
- Gradient settings preserved during YOLOE layer conversion

## Dataset Handling

- Classification auto-splitting recognizes all supported image formats (JPEG, BMP, WebP, TIFF, AVIF, HEIC)
- Missing classification images raise `FileNotFoundError` with clear messaging
- Original filenames preserved after EXIF correction
- Bounding-box fallbacks for malformed grounding segmentation labels
