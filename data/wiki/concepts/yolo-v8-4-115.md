# YOLO v8.4.115

Ultralytics YOLO v8.4.115 릴리스 (2026-08-01). 레거시 HUB 통합 제거 및 Ultralytics Platform 전환.

## Release Summary

v8.4.115는 레거시 HUB 통합을 제거하고 새로운 [Ultralytics Platform](https://platform.ultralytics.com/) 경험으로 전환하는 주요 릴리스다. 더 단순한 인증 및 간소화된 학습 코드베이스 제공.

## Key Changes

**Platform CLI 인증**^[inbox/fetch-2026-08-02-yolo.md]
- `yolo login API_KEY` 명령어로 로그인
- `yolo logout`으로 인증 정보 제거
- API 키는 저장 전 Platform에서 검증

**설정 마이그레이션 (schema 0.0.7)**
- 기존 호환 설정(커스텀 데이터셋/실행 디렉토리) 보존
- 레거시 HUB 설정 및 비호환 API 키 자동 제거
- 기존 사용자는 Platform API 키 생성 필요

**레거시 `ultralytics.hub` 패키지 제거**
- HUB 인증, 원격 학습 세션, 모델 로딩, 내보기, 데이터 유틸리티 제거
- HUB 관련 API 참조 및 문서 페이지 제거

**모델 및 트레이너 워크플로우 간소화**
- HUB URL에서의 직접 모델 로딩 중단
- HUB 세션, 원격 체크포인트, 하트비트 관리 제거

## Migration Guide

```bash
# Platform API 키 생성 후 인증
yolo login YOUR_API_KEY
```

## Compatibility

- ⚠️ `ultralytics.hub` 임포트, HUB 학습 세션, HUB URL 모델 로딩 사용 애플리케이션은 Platform 워크플로우로 마이그레이션 필요
