# YOLO v8.4.203 릴리스 (2026-11-05)

Ultralytics 공식 GitHub 릴리스 노트(v8.4.203, 2026-11-05) 기준 요약이다.^[inbox/processed/fetch-2026-11-06-yolo.md]

## 요약
NXP i.MX95 Neutron NPU 내보내기가 추가되고, 로딩 보안 강화와 학습·추론·추적·시각화 전반의 수정이 포함됐다.

## 주요 변경사항
- **NXP i.MX95 내보내기**: `format=nxp`로 Neutron SDK 3.3.0 기반 INT8 LiteRT 모델을 생성한다. 7개 YOLO 태스크를 모두 지원하며 기존 LiteRT 추론 백엔드에 NXP delegate를 사용한다. 대상은 **i.MX95 전용**이고, 미지원 연산은 CPU에서 실행될 수 있다.
- **안전한 로딩**: 데이터셋 캐시에 제한된 unpickler를 적용하고, 체크포인트가 패키지를 자동 설치하지 않는다(의존성 누락 시 설치 대신 오류). SAM·NAS·YOLO-World·YOLOE 로딩 경로는 가능한 곳에서 weights-only 로딩을 쓴다.
- **학습 수정**: YOLOE 텍스트 프롬프트 학습의 소수 클래스 처리, 손 키포인트 flip 시 랜드마크 대응 유지, 결정론적 시맨틱 세그멘테이션 손실 계산 속도 개선.
- **추론·추적 수정**: SciPy 폴백 추적기의 할당이 더 나은 매칭을 찾음. FastSAM 박스 프롬프트가 모든 마스크를 벗어나면 선택 없음, 중단된 "segment everything" 이후에도 SAM 프롬프트 재사용 가능.
- **유틸리티·문서**: mask-IoU 자료형 처리, 모델 변환 후 백엔드 정밀도 갱신, ExecuTorch 캡처, 이진 시맨틱 마스크 렌더링, PIL 텍스트 위치 수정. Argoverse는 Google Drive 대신 Ultralytics Platform으로 내려받는다.

## 목적·영향
- i.MX95 사용자는 기존 내보내기·추론 흐름으로 Neutron 하드웨어용 모델을 만들 수 있으나, 배포 전 대상 보드에서 정확도·지연·CPU 폴백을 검증해야 한다(릴리스 노트 권고).
- 신뢰할 수 없는 캐시·모델 파일로 인한 위험이 줄어든다.
- 결정론적 시맨틱 손실의 속도 향상은 집중 측정치이며 전체 학습 속도를 보장하지 않는다.
